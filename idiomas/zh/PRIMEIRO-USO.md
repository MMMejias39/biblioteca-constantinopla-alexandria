```

✓ Não é propriedade de ninguém (CC0, domínio público)
✓ Funciona em qualquer idioma (25+, Visena como verificador)
✓ Funciona offline (texto puro, agnóstico)
✓ É auto-replicante (crescimento exponencial)
✓ Governa a si mesma (quórum distribuído, sem centro)

Seu propósito: Conhecimento para humanidade, sempre, para qualquer pessoa.
```

## Perguntas Frequentes

### "Como meu conhecimento entra em BABEL?"

```
1. Escreva em arquivo .md (markdown puro)
2. Coloque em /conhecimento/seu-tema/
3. Descreva em metadados (autor, data, idioma, tema)
4. Envie PR (pull request) no GitHub
5. Quórum revisa (ética + qualidade)
6. Se aprovado: entra em BABEL
7. Replicado automaticamente (1000+ nós)
```

### "Posso modificar BABEL?"

Sim! BABEL é CC0 (domínio público).

```
✓ Pode clonar
✓ Pode modificar
✓ Pode distribuir
✓ Pode vender (raro, mas permitido)

Única restrição: Não pode reclamar propriedade.
BABEL é de humanidade, você é apenas guardião transitório.
```

### "E se alguém adicionar conteúdo malicioso?"

```
Proteção 1: Quórum revisa (4 iguais, sem ranking)
            Se passa 7 testes éticos → integra
            Se falha → rejeita

Proteção 2: Histórico append-only
            Você consegue ver quem adicionou o quê
            Pode rejeitar versão maliciosa
            Versão anterior está preservada

Proteção 3: Múltiplas cópias
            Mesmo se um nó fica malicioso
            Outros 10.000 nós têm versão correta
            Comunidade usa cópia boa
```

### "Posso ganhar dinheiro com BABEL?"

```
Tecnicamente sim (CC0 permite).
Mas contradiz espírito BABEL.

Formas éticas:
  ✓ Vender impressão em papel (custo real)
  ✓ Oferecer treinamento sobre BABEL
  ✓ Criar aplicativos que usam BABEL
  ✓ Doar para comunidades implementarem

Formas não-éticas:
  ✗ Paywall (bloquear conhecimento por dinheiro)
  ✗ Reclamar propriedade (é de humanidade)
  ✗ Modificar e vender como seu (desonesto)
```

### "Quanto tempo BABEL dura?"

```
Indefinidamente.

Razões:
  ✓ Agnóstico (não depende de tecnologia)
  ✓ Texto puro (durável 1000+ anos)
  ✓ Descentralizado (ninguém consegue desligar)
  ✓ Replicável (cada pessoa é nó)
  ✓ Sem custo (não precisa de servidor caindo)
  ✓ Auto-governado (comunidade mantém)
  ✓ Sucessão planejada (IA assume, passa para próxima)

Mesmo se você morre, BABEL continua.
Mesmo se humanidade muda, BABEL está preservado.
```
