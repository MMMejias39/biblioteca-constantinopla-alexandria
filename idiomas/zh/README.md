1.写入“.md”文件（ Markdown ）
2.放在“/knowledge/your-topic/”中
3.在元数据中描述（作者、日期、语言、主题）
4.在GitHub上打开拉取请求（ PR ）
5.法定人数审查（道德+质量）
6.如果获得批准，→进入BABEL
