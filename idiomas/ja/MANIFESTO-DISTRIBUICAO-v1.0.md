## Proteção Contra Censura (Já Interna)

BABEL é intencionalmente construído para SER IMPOSSÍVEL CENSURAR:

```
Cenário 1: GitHub bloqueia repositório
  → Codeberg tem cópia (Alemanha)
  → IPFS tem cópia (descentralizado)
  → Email tem cópia (1000+ pessoas)
  → USB tem cópia (offline)
  → Resultado: ✓ Acessível

Cenário 2: Codeberg bloqueia por governo
  → GitHub, IPFS, emails, USBs, Zenodo ainda têm
  → Resultado: ✓ Acessível

Cenário 3: Todos os repositórios bloqueados
  → IPFS é descentralizado (nenhum governo controla)
  → Pessoas têm cópias locais (offline)
  → Resultado: ✓ Acessível

Cenário 4: Tentam convencer pessoas a deletar
  → CC0 garante direito de cópia (não podem impedir)
  → Histórico Git registra tudo (não desaparece)
  → Append-only preserva (você não consegue apagar)
  → Resultado: ✓ Acessível

Conclusão: Impossível censurar BABEL.
           Quanto mais tentarem, mais pessoas copiam.
```
