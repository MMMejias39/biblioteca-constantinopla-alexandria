# Protocolo de Preservação (núcleo Constantinopla)

## 1. Regra 3-2-1
Três cópias de cada obra essencial, em dois tipos de mídia, com uma cópia fora de casa. Nenhuma cópia única nunca.

## 2. Formatos abertos
PDF/A para documentos, EPUB para livros, `.zim` para coleções offline (Kiwix), WARC para páginas da web, Markdown/JSON puro para catálogos. Evite formatos proprietorários sem conversor documentado.

## 3. Espelhamento
- Internet Archive como espelho público externo para obras próprias publicáveis.
- Repositório Git remoto para o catálogo desta biblioteca.
- Pelo menos um espelho em jurisdição diferente do principal.

## 4. Acesso offline
- Kiwix + bibliotecas `.zim` (Wikipédia, WikiMed, Gutenberg) para pontos de acesso comunitários.
- Kolibri em contexto escolar sem conexão.

## 5. Cautela jurídica (lição de 2024–2026)
O caso *Hachette v. Internet Archive* mostra que até as maiores bibliotecas digitais perdem litígios. Estratégia:
- Coleção **essencial** = obras de domínio público, Creative Commons ou open access (Gutenberg, Wikimedia, DOAJ, OER).
- Cópias privadas apenas de obras que cada participante possui legalmente.
- Nunca tornar a biblioteca dependente de uma única plataforma sob risco jurídico.

## 6. Ciclo de verificação
Semestral: conferir links, licenças e disponibilidade de todas as entradas dos catálogos; registrar a data da última verificação.
