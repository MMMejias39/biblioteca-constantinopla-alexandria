# Nomenclatura Mnemônica — Nome que Perdura na Memória

**Problema:** "Biblioteca Constantinopla–Alexandria" é descritivo mas longo, difícil de lembrar, não cabe em SMS.

**Solução:** Nome mnemônico que seja fácil de pronunciar, compartilhar e lembrar indefinidamente.

---

## I. Critérios para Nome Mnemônico

```
✓ BREVIDADE
  - Máximo 6 letras (cabe em SMS, fácil digitar)
  - Uma sílaba ou duas
  - Sem acentos (compatível universal)

✓ MEMORABILIDADE
  - Relacionado a conceito conhecido
  - Fácil de pronunciar
  - Sem ambiguidade
  - Funciona em português E inglês

✓ REPLICABILIDADE
  - Fácil de compartilhar oralmente
  - Fácil de escrever à mão
  - Funciona em qualquer idioma
  - Reconhecível mesmo com erros de ortografia

✓ ATEMPORALIDADE
  - Não fica "datado" em 5 anos
  - Não é moda (pode soar estranho depois)
  - Não é nome de pessoa (evita segregação)
  - Não é marca registrada (risco legal)

✓ UNIVERSALIDADE
  - Não é específico de cultura
  - Respeita CARE (não apropria nada)
  - Representa conceito humano universal
  - Funciona em múltiplos idiomas
```

## III. Escolha: **BABEL**

### Justificativa

```
Entre os candidatos, BABEL melhor atende aos critérios:

Brevidade:
  ✓ 5 letras (fácil digitar)
  ✓ Cabe em SMS
  ✓ Fácil escrever à mão

Memorabilidade:
  ✓ Qualquer pessoa conhece referência
  ✓ Culturalmente reconhecido (história/mitologia)
  ✓ Não ambíguo
  ✓ Fácil pronunciar em português/inglês

Replicabilidade:
  ✓ Fácil contar para alguém
  ✓ Pessoas lembram imediatamente
  ✓ Funciona em múltiplos idiomas (Babel é universal)
  ✓ Nem erros de ortografia afastam do significado

Atemporalidade:
  ✓ Não é moda (existe há 2000+ anos)
  ✓ Não envelhecerá em 5, 50 ou 500 anos
  ✓ Referência histórica (não marketing passageiro)

Universalidade:
  ✓ Conhecida em múltiplas culturas (não é apropriação)
  ✓ Representa multiplicidade + comunidade
  ✓ Conceitual: múltiplas formas = conhecimento descentralizado

Significado Duplo (Positivo):
  - Conotação negativa: confusão, incompreensão
  - Conotação positiva: multiplicidade, abundância, pluralismo
  → Sistema é sobre multiplicidade (não ponto central)
```
