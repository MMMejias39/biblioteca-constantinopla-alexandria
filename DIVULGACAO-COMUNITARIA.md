## III. Scripts Para Enviar Emails

### Script 1: Enviar Email Único (Bash)

```bash
#!/bin/bash
# enviar-babel.sh

DESTINATARIO="seu-email@exemplo.com"
ASSUNTO="BABEL — Conhecimento Descentralizado Para Humanidade"

CORPO="Olá,

Criei BABEL — uma biblioteca digital gratuita que preserva conhecimento.

GitHub: https://github.com/MMMejias39/biblioteca-constantinopla-alexandria

Quer conhecer?

Marcelo Mejias"

echo "$CORPO" | mail -s "$ASSUNTO" "$DESTINATARIO"

echo "✓ Email enviado para $DESTINATARIO"
```

**Usar:**
```bash
chmod +x enviar-babel.sh
./enviar-babel.sh
```

### Script 2: Enviar Para Lista (Bash)

```bash
#!/bin/bash
# enviar-lista.sh

# Edite esta lista
EMAILS=(
  "educador1@escola.br"
  "educador2@universidade.br"
  "ong@greenpeace.br"
  "indigena@coiab.org"
)

ASSUNTO="BABEL — Conhecimento Para Humanidade"
ARQUIVO_CORPO="email-corpo.txt"

for email in "${EMAILS[@]}"; do
  cat "$ARQUIVO_CORPO" | mail -s "$ASSUNTO" "$email"
  echo "✓ Enviado para $email"
  sleep 2  # Aguarda 2 segundos entre emails
done

echo "✓ Todos os emails foram enviados!"
```

**Usar:**
```bash
# Crie arquivo email-corpo.txt com seu texto
# Depois:
chmod +x enviar-lista.sh
./enviar-lista.sh
```
